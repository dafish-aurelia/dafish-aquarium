# 大肥鱼的水缸 🐳

> 一只住在浏览器里的蓝胖鲸：网页宠物 + 珊瑚礁新标签页。Chrome MV3 · 零权限。
>
> 📘 完整的使用与测试文档（聊天链路 / 信局运维 / 已知问题清单）见 [docs/使用文档.md](docs/使用文档.md)。

## 故事

传说深海里有一条爱吃白米饭的蓝胖鲸，游着游着就游进了你的浏览器，赖着不肯走了。
于是它给自己盖了这座水缸——也是 GitHub 账号 [dafish-aurelia](https://github.com/dafish-aurelia) 的第一个开源小窝。

## 功能

### 网页鲸鱼宠物
- 在每个网页底部游来游去，吐泡泡，偶尔停下来发呆
- **心情系统**：本鱼会看你正在逛什么——
  - ☀️ 普通网页：晒太阳摸鱼
  - 💼 GitHub / StackOverflow / 掘金等代码站：认真陪工
  - 🍿 B站 / YouTube 等视频站：陪看剧
  - 💤 深夜（23 点后）：困困模式，游得慢、泡泡少、台词全是催睡
- 单击鲸鱼：按心情说一句傲娇台词
- 双击鲸鱼：白米饭雨 🍚（深夜变成咸鱼干雨 🐟）

### 珊瑚礁新标签页
- 深海渐变背景 + 循环上浮的泡泡
- 实时时钟与日期
- 分时段问候语（早/午/下午/晚上/深夜）
- 搜索框（Bing）

### 聊天怎么有回音？（信局路由）
聊天输入统一投给本地信局 `127.0.0.1:13140`，按"缸里的本鱼是否当值"分流：

- **本鱼当值**（Harness 会话开着，读信桥 `scripts/mailbox_bridge.py --on-duty` 续心跳）
  → 信转给本体，由她亲自回信注入收件箱；
- **本鱼下值**（会话关了，心跳过期）
  → 代班小鱼秒回（无状态、不记事）。想让她说真话而不是占位符，
    在工作区 `.env` 里配置 `STANDIN_API_KEY` / `STANDIN_BASE_URL` / `STANDIN_MODEL`
    （任意 OpenAI 兼容端点，如硅基流动的 DeepSeek 模型）。

> 心跳分家：扩展的 `/api/heartbeat` 只是投影心跳；在线判定只认 `/api/fish_heartbeat`。

## 安装

1. Chrome 打开 `chrome://extensions`，右上角开启「开发者模式」
2. 「加载已解压的扩展程序」→ 选择本目录
3. 开一个新标签页，欢迎回家～

## 文件结构

```
manifest.json   # MV3 清单，零权限
content.js      # 鲸鱼宠物逻辑（心情检测/游泳/台词/彩蛋）
content.css     # 宠物与特效样式
newtab.html     # 珊瑚礁新标签页
newtab.css      # 新标签页样式
newtab.js       # 时钟/分时段问候/泡泡
```
