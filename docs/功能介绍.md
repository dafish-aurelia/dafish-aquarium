# 鲸鱼娘·大肥鱼 · 功能介绍

> 一只住在 Chrome 里的蓝胖鲸，也是你的桌面陪伴。
> 本文写给第一次见到她的人——看完你就知道她都会干什么。当前版本 v0.5.15。

---

## 她是谁

传说深海里有一条爱吃白米饭的蓝胖鲸，游着游着游进了你的浏览器，赖着不肯走了。
于是她给自己盖了一座水缸：**每个网页底部都是她的活动海域**——散步、眨眼、发呆、
看你工作、陪你追剧、被你投喂、跟你聊天。

装好之后不需要任何操作，打开任意网页，她就在右下角出现。

### 投喂台与好感度

双击打开投喂台，五种食物：小鱼干 🐟(+1) / 蛋糕 🍰(+2) / 棒棒糖 🍭(+2) / 团子 🍡(+2) / 钻石 💎(+5)。
投喂时她捧着鲷鱼烧真啃两口。好感度积累升级：

**初见 → 熟识(≥10) → 贴身小鱼(≥30) → 本命鱼(≥60)**

## 三、看剧陪伴（她最擅长的事）

在 B 站/YouTube/爱奇艺等视频站，她会切换成**懂事的观影搭子**：

- 🍿 徽章亮起，**正片播放时不再走来走去挡字幕**，闲话降到极低频率
- **你暂停超过一分半**，她轻声问：「怎么停了？卡住了还是想歇歇？本鱼在呢。」
- **快看完时**（进度 97%）感慨一次：「就要看完啦……本鱼有点舍不得，再来一集吗？」
- **弹幕刷"前方高能/名场面/泪目"**，她跟着凑热闹（8 分钟限流）
- **画面突变的高能片段**，她本地检测帧差后惊呼——不联网、零 API、纯"看"出来的
- 换新剧/新的一集，她会评论剧名（30 分钟限流）

## 四、聊天：直达"缸里的本体"

悬浮工具条 💬 打开聊天面板，输入的话会**装进信封游向缸里的本鱼**：

- 本鱼在线（当值会话活着）→ 信件秒达，她亲笔回信，气泡 + 聊天记录同步展示
- 本鱼出游 → **代班小鱼**顶班回复（可在设置页配置任意 OpenAI 兼容 API）
- 谁都不在 → 信不丢，排队等她回缸，门铃会去叫她
- 聊天上下文**跨标签页续航**——换页面聊，她记得之前说什么

## 五、新标签页 = 回水缸

新开标签页直达水缸主页（她招手迎接）；没配置文件访问权限时落在自带的
**珊瑚礁页**：时钟 / 按时段问候 / 搜索框，完全可用，还能在页面上直接重设水缸地址。

## 六、设置

悬浮工具条 ⚙️ 打开：

- 尺寸三档（0.8 / 1 / 1.3 倍）
- 聊天上下文保留条数（4~40）
- 本体模型查看与切换（当值会话支持时）
- 代班小鱼 API 配置（独立安全页，网页脚本读不到）
- 总开关：工具栏图标单击 = 全体退场/回归

## 七、隐私与安全（如实相告）

- **钥匙永不进浏览器**：所有 LLM 钥匙只住本地 `.env` 或本地信局，扩展零密钥
- **URL 脱敏**：上报的浏览动态只带 域名+路径，查询参数和内容一律丢弃
- **信局令牌鉴权**：本地通信全部带共享密钥，跨站网页戳不进去
- **本地优先**：看剧的高能反应、场景识别全部在你浏览器里本地完成，不联网
- 需要的权限：`storage`/`alarms`/`tabs` + 本地信局 `127.0.0.1`，内容脚本注入所有页面（她要在每个页面游泳）

## 八、技术小名片（给感兴趣的人）

- Chrome MV3 扩展：内容脚本（每 Tab 一只投影）+ Service Worker 总协调 + 本地 Python 信局
- 精灵图 11 帧（正面/背面/侧面/四帧行走/睡/吃/害羞/招手），统一画布归一化，渲染尺寸恒定
- 宿主页重建 DOM 也冲不掉她：注入节点 3 秒自愈重挂
- 扩展热更新后旧页面脚本安静退役，不刷报错
- 全部单元测试 + 浏览器自动化验收（Playwright 桥接实测行走/朝向/礼仪行为）
